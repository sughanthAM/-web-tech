Web Fundamentals

1. Internet Overview

The Internet is a global network of interconnected computers that communicate using standardized protocols (TCP/IP) to share data, resources, and services across the world.

2. Fundamental Computer Network Concepts

  • Node: Any device connected to the network
  • IP Address: Unique numerical identifier for each device
  • Protocol: Rules governing data communication (HTTP, TCP/IP, FTP)
  • Bandwidth: Data transfer capacity of a network

4. Domain Name

A domain name (e.g. example.com) is a human-readable address mapped to a numeric IP address via DNS (Domain Name System), so users don't need to remember IP numbers.

5. Web Browsers and Web Servers

Web Browser: Client software (Chrome, Firefox) that requests and renders web pages.
Web Server: Software/hardware (Apache, Nginx) that stores and delivers web pages to browsers on request.
